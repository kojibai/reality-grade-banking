# Client work: interactive search entrances

The relationship Workspace has shipped in source. This release connects practical search entrances to an interactive, local demonstration of its real Messages presentation. A visitor can read a client brief, open Workspace, move between Twin / Work / Context, edit a proposal, invoice, document or agreement, preview the actual file, download it and add the draft to the fictional conversation. It uses shared editors and the production pure exporters.

The demonstration opens no account and calls no AI, message transport, identity, storage, signing or payment operation. People and replies are fictional; Twin replies are explicitly scripted. Downloaded files are authored content without an enclosing Original, agreement consent, signature or payment evidence. The existing account entrance remains `/#account/messages`. Business AI usage retains its current access, pricing and review boundaries.

Critical styles are carried with that page; no API or account prerequisite precedes the visible conversation. Portable file code and PDF rendering load after an explicit preview action.
