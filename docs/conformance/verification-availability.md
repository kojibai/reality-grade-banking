# What the conformance tools can independently establish

This is an availability ledger for the existing receiving standard, not a
relaxation of its requirements. All applicable requirements must pass the
production assessment. Missing proof means **does not pass**, with the reason
**required proof missing**; it does not prove that an unobserved operation
violated a law. Complete raw sources, exact test inputs and independent
execution remain stronger than a copied diagnostic report.

The machine-readable registry marks each item as **partial automated
verification; independent production evidence required**. The current public
source verifier has no method that certifies an institution's durable storage,
all concurrent future executions, privacy controls, hardware rollback behavior
or independent live assessment. The software therefore cannot truthfully award
a complete production-profile PASS from a file upload. Unsupported proof
formats or assessment authority remain explicit rather than being accepted
through a caller-supplied verifier callback or `passed:true` field.

The active public contract testbench has a real PASS path, and Bankeiz's
engineering suite has a real recorded PASS path. Those scopes are distinct
from full production readiness. The full profile may be assessed independently
with actual evidence and the published qualification procedure; no project
operator or paid badge grants an exception to its laws.
