# Global Market Cap calculation disclosures

The Market info panel exposes the exact public calculation under **Valuation
protocol & source accounting → Exact market-cap calculation**. It uses the
same completed publication as the headline and chart.

The current quote and capitalization pass retains its existing operands:

- Each included canonical asset, counted once, with its exact running subtotal.
- Unit quote, counted microshares, issued/held quantities, certificates and
  available buying capacity. Existing native offers remain part of issued supply.
- Integer microshare multiplication, per-asset cent rounding and integer summation.
- Collectible copy values or the actual aggregate model and its rounding. A
  carried aggregate is never presented as a uniform per-copy price.
- Original frequency, intrinsic Φ, rounded market Φ, the existing USD/Φ quote,
  and the exact USD-cent branch.
- The selected period’s carried endpoints, signed delta, percentage truncation
  and chart points.

The calculation is bound to the existing history-basis digest, public source
hash, evaluation pulse, coverage and amount. An older or differently scoped
calculation cannot explain a newer headline, even when its amount is equal.
This is explanatory display data; it grants no ownership or execution authority.

## Keep normal use light

The worker captures operands during the valuation it already performs. Inspection
reads that completed result; it neither fetches a source nor starts another
market valuation. It does not cancel an in-flight publication.

The detailed collection stays in the worker while the panel is closed. It is
not added to stored chart history, repeated pulse inputs, or initial page data.
Opening details requests the retained result once. A matching result already
held by the interface is reused on reopening. Closing a parent disclosure stops
inspection updates. A worker restart retains the normal completed chart flow.

Asset and copy lists initially render 24 summaries. Nested sections mount only
when opened. Canonical SDK explanatory terms are generated only for an explicitly
expanded Original, cached by its immutable calculation frame, and required to
match that frame’s value. The deepest quote section exposes the existing quote
implementation and policy rather than maintaining another pricing engine.

Missing coverage and missing individual bases remain explicit. Disclosures
never invent earlier quantities, reprice a completed record, rewrite an Original,
or alter a financial rule. Historical point lists use the chart’s held records.
