# Originals explanation refinement

## User direction and preserved primitives

Keep the actual Create/Sign app walkthrough, working Original verifier, value
replay and altered-content test. Refine the weaker explanatory presentation.
Introduce the idea through familiar work and elapsed years; keep exact Kai
coordinates in the deeper evidence and calculation interfaces.

The Original verifies. A duplicate presented as a new entitlement is rejected.
A copied signature cannot replace this Original's accepted signing history.
These are separate boundaries; the page must never describe a later copy as
though it were a new Original or an additional allocation.

## Presentation

The familiar example is a person's first book, sealed today and inspected years
later. Its source, original beginning, current ownership and accepted history
remain inspectable. Four steps lead through creation, signature, later
verification and subsequent use. One custom cobalt/glass illustration anchors
that source. Bounded CSS motion uses the existing visibility observer and stops
for reduced-motion readers or when offscreen.

The page retains its established value language and working product examples.
Six reading paths lead to value law, personal origination, signing/publication,
ownership, value development and actual banking. The live proof demo preserves
all original controls and request behavior.

writer, package version, account-entry or database change. The Moments animation
keeps its same source identity, conserved example amounts and eight scenes;
the duplicate scenes now explicitly label the refused claim.
