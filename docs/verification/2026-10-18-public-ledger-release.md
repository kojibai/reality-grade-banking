## Primitive preserved

Original canonical v129 bytes, existing roots and source-domain signatures
remain authoritative. The native disclosure covers complete declared public
**action history**, not a wallet balance or every public display feed. An observed
baseline remains observed. The image transports the exact source; printed text,
QR, index rows and copied flags do not establish funds or ownership.

## Risk boundary

No live publication, identity enrollment, hardware custody or money movement was
performed. Native history export requires an operator-approved exact source head.
Automatic approval review rejected automatic native-history disclosure; the
implemented safer route refuses absent or advancing disclosure authorization.
User publication separately binds explicit public-copy consent to the reviewed
original digest. Private identities, encrypted signing material, recovery/custody
sources and spendable notes are refused.

Prepared financial credit and generic asset execution selectors remain subject
to [current function boundaries](../current-function-boundaries.md). This is not
a claim that every financial feature is enabled in production. No Vercel
production deployment or live financial acceptance was performed.

## Rulings made

- Existing Merkle/display records retain their integrity-only scope. A canonical
  root-authenticated native public projection carries its own explicit action
  history scope. Cost if wrong: unrelated display families are not exportable as
  verified financial history.
- Private native commands and account payloads are excluded; only closed public
  fields and source/head commitments are disclosed. Cost: the public disclosure
  is not a substitute for the private native execution source.
- Generic actions are not coerced into wallet event types. Cost: consumers must
  read the declared public-action scope rather than assume a wallet balance.
- The public Crystal uses the existing Ledger PNG keyword and canonical source;
  private intelligence Crystals are not relabeled as public Ledgers. Cost: an
  unsupported private carrier refuses rather than being silently imported.
- Full native Ledger JSON may be compressed before sealing, bounded to64MiB and
 100,000 rows, within16MiB canonical enclosing capacity. Cost: larger complete
  sources refuse until a qualified larger-capacity source transport exists.
- Native disclosure requires exact-head approval after automatic approval review
  rejected unconditional publication. Cost: later native history requires another
  disclosure decision; prior approval never silently exposes new account data.
- The deployed public relay accepts4MiB JSON uploads; local original/PNG limits
  remain16/24MiB. Cost: larger originals remain locally usable but public upload
  needs a separately qualified transport. No history is truncated to fit.

No deferred minors.
