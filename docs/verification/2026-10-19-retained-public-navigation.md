# Retained public navigation

The public guides, Reality-Grade Banking, legal notices, schema reference,
Explore, Ledger, Verify, Conformance and receipts share the same document
navigation. Each address remains a complete directly openable document.

## Behavior

- Guide markup and exact workspace CSS travel in the public build payload.
  Selecting a page paints carried content immediately; it does not fetch a
  replacement HTML document or wait for a destination stylesheet.
- Public React entries execute on selection. Each workspace mounts once and
  retains its search, selected tab, form and source state on return. Pointer or
  keyboard intent may preload module bytes without executing an identity or a
  hidden workspace.
- The private Bank root remains mounted and inert while away. Cold entry from
  a public guide already carries the real account-opening artwork and emitted
  CSS. Private identity code still executes only after choosing the Bank.
- Hidden Explore and Ledger feeds, valuation workers and Kai Klok cadence are
  paused. Hidden Conformance motion pauses. Receipt valuation cadence pauses
  while its exact in-memory causal evidence remains held.
- One selected receipt owner avoids duplicate hidden receipt rendering. An
  explicit reopening refreshes its current in-memory source context; ordinary
  Back retains the already selected receipt. No additional source request is
  needed for this navigation.
- Shared `/verify/<digest>/` links select their carried Verify runtime. A
  different digest aborts the previous public read and clears the old result;
  a stale completion cannot overwrite the new source.
- Metadata, canonical URLs, robots directives and receipt referrer policy
  follow the selected page. Same-page anchors, modified clicks, downloads,
  external destinations and payment query links retain their ordinary meaning.
- The Conformance runtime remains separate from the Bank import graph and
  installation cache. No account API or private evidence is precached.

The first visit to an interactive workspace can still load its selected code
and existing public data. Subsequent visits reuse that mounted workspace.
Navigation does not manufacture current source data or bypass verification.
