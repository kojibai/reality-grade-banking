# Local Note panel opening

Opening Notes previously prepared protected identity transport and enrolled or
checked the document signer before reading saved notes. Missing enrollment could
contact the enrollment service and save a key. Existing enrollment could fail
while signing with a retained CryptoKey. Neither operation belongs to preview.

The memoized panel API now reads the two encrypted financial state families
locally and restores complete original images through pinned v129 inspection.
Its inspection-only runtime has no request, fetch, signing or write ports.
Clear-original identities can open empty or retained local inventory without
first constructing protected transport. Signing/execution setup starts only
after an explicit action. Preview and Review do not start registration.

Malformed or unreadable custody remains an error, never an empty state. Prepared
records require their existing containers and original image references. Saved
prepared attempts remain visible while prepared credit execution is disabled.
Both-family conflicts and disabled prepared recovery block fresh legacy
allocation, with a second check inside the existing cross-tab operation lock
after asynchronous setup. Existing epoch, exact-amount, CAS, funding, admission
and hardware antirollback checks remain intact. No financial record is erased,
generation-isolated or reset.

Review is unavailable until saved/pending discovery completes. Failures can show
only the bounded stage and exception name; original private messages, keys,
credentials and account fields do not enter those details. This distinguishes
local state decryption, original restoration, transport and signer setup. The
actual iPhone exception site and the reported later Face ID appearance remain
unconfirmed; no device capability is inferred from a generic OperationError.

Verification: 1,055 tests in 199 files and the full production build pass.
Regressions cover clear-original opening without enrollment/sealing/connection,
unreadable custody before signing, malformed prepared data, pending discovery,
competing setup-time attempts, disclosure bounds and quote/action epochs.
Isolated browser UI opening and Review use synthetic ports with no account or
money connected. No live funding, transfer, Safari/iPhone credential enrollment
or hardware qualification was performed.
