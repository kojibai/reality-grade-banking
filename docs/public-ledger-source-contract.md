# Public Ledger source contract — v129

The public reader combines the existing action, wallet, Proof Graph and public
showcase display sources. Those rows remain public projections. Their presence,
prices and receipt links do not establish a spendable balance.

The native source adapter discloses the supported public view of the **same
verified native Action Ledger** used by Receiz. It does not create another ledger
or account writer. The declared scope is `public-action-history`; the complete
accepted native source history, exact row references and real carried Kai are
preserved. Other public feed families are not silently promoted into that scope.
An imported/migrated observed baseline is identified as observed, rather than
presented as newly admitted financial truth.

The adapter opens an actual runtime-admitted `ActionLedgerHistory`. A JSON clone,
API response, cached array, supplied count, Merkle root or `verified` flag cannot
substitute for that source. It derives closed public fields, retains native
source/predecessor commitments and signs the resulting disclosure under the
existing native issuer. It seals the exact disclosure with the canonical v129
sealer and reopens it with the same canonical verifier before retaining it.
No original private commands, account UUIDs, login material, recovery records or
funding credentials are included in the disclosure.

The public reader verifies both enclosing source integrity and the supported
Ledger statement's actual issuer and scope. The writer does not assert new
ownership, finality, money or account funds by sealing arbitrary uploaded JSON.
`financialAdmission` is always false. Public object admission, custody and any
financial effect keep their existing independent v129 requirements.

A single original proof and a Memory Crystal use that same source verification.
Carrier metadata, artwork, QR codes and links are transports. Whole-history
synchronization preserves exact accepted history; proof discovery identifies
supported independently verified objects without rewriting another object's
history. Complete source data is distinct from the visible row window.

A native source that is absent, incomplete, missing its original coordinate, or
outside supported capacity is refused. It is never replaced with an empty
verified Ledger or converted from unsigned display rows.
