## Implementation evidence before the versioning commit

- The Bankeiz suite ran 1,198 test files with 7,804 passing tests and 11 skips.
  The production build passed the Bank entrance, Discovery, and Feed budgets,
  the account entry freeze, offline shell, and corresponding source checks.
  A clean corresponding-source replay reproduced 229 SDK JavaScript outputs.
- Compiled browser checks opened the anonymous pages with external reads
  stalled. They verified the selected payment carried into Ledger, publication
  of a later accepted event, and both events on an independent cold Ledger open.
  Chrome and WebKit fixtures exercised mobile Messages and the compact desktop
  view.
- Contract and application fixtures cover exact Original ranges, conflicts over
  the shared whole-and-piece head, reassembly and direct ownership delivery,
  currency allocation and pool pricing, currency transfer and Note redemption,
  and the linked governance controls. A native writer fixture covers Bankeiz
  Open Note issuance, one credit on duplicate delivery, and exact recovery
  after an interrupted response. These runs used test funds.
- Wallet fixtures cover an ordinary nearby handoff, mixed QR routing, retention
  and recovery of the exact signed debit, and witness-backed spend continuity.
  The physical iPhone Home Screen fixture recovered the exact signed test
  debit of $60 and computed the remaining $40 offline from the selected Files
  checkpoint. The browser witness and original test signer were absent, so the
  run stopped before another offline debit. Automatic signer recovery and
  offline spending after a complete erase remain unqualified.
- The signed Android artifact declared in `public/downloads/android-release.json`
  is `Bankeiz-8.0.0.apk`, with SHA-256
  `c92a5f822d62c69758755f93aa178ad98a12b02737c2722bf9d31e94a8f602e9`.
  Android hardware observations establish the evidence captured in the
  diagnostic. Physical send, receive, respend, and restore on a matching
  production Android build each require their own result.

## Versioned source qualification

Bankeiz `38d3764b999dceb85be2c447d99e8c2e3198f101` is the first 9.0.0
versioning commit. The full suite passed 7,804 tests with 11 skips. The production
build passed its account-entry and page-size checks. Compiled browser fixtures
verified held history, later accepted updates, and the Messages layout. A
clean corresponding-source extraction reproduced the full build and 229
SDK JavaScript outputs. [GitHub Actions](https://github.com/kojibai/reality-grade-banking/actions/runs/45785981231)
tracks the separate CI result for that commit.
