## Publication and scope

The [release process](../release-process.md) covers the exact source archive,
native reproduction, CI, authorized publication, and deployed verification.
The versioned repository release uses this record, the matching source and
license notices, and the tag that identifies the release commit. Hosted CI and
deployment results are independent of local qualification. No new receipt,
private account export, production settlement, protocol migration, or separate
SDK release is part of the v7 release verification.
