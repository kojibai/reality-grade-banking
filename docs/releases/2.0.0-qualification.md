## Infrastructure and integration

Receiz provides the underlying infrastructure through the coordinated **SDK,
MCP and AI Skills 129.0.0**. Bankeiz owns its interface, integration adapters,
explicit approvals, local encrypted retention and result presentation. Receiz
provides the supported identity, proof, financial and communication contracts.

The included dependency source and provenance support exact reproduction of
distributed modules. They do not grant production access. This release records
the Bankeiz composition and integration, with Receiz consumed through its
published contracts.

Use the registered application's actual Receiz capabilities and permissions.
Unsupported or unavailable operations remain explicit refusals. Keep private
identity material and grants out of public configuration and release artifacts.

## Assessment boundary

This preparation executes local verification and public read-only browser checks.
It does not charge a card, trade, issue/deposit a live Note, publish an asset,
send a message, place a call or exercise phone Web Push.

User-reported live purchases, sales and Note creation/deposit are retained as
product observations. They are not substituted for an independent inspection of
private receipts or full deployment/device qualification. Actual hardware,
network calls, protected offline custody, push delivery, admitted Settlement
funding, merchant fulfillment and exact deployment assessment remain specific
to their tested sources and operator records.
