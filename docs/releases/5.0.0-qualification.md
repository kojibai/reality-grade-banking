## Evidence classes

1. Source and installed-contract review establishes what the implementation
   composes and preserves.
2. Local tests and controlled browser fixtures establish their actual assertions,
   source and synthetic assumptions.
3. A public readback establishes the particular returned source and receipt.
4. A real financial or protected-device outcome requires its exact operation,
   originals, authority and applicable device evidence.
5. Release publication identifies an immutable tag, distributed source and
   matching hosted build.

These classes are recorded separately. A local pass or successful HTTP response
cannot replace the acceptance evidence required by another class. Historical
counts below are not additive and are not a fresh final-v5 aggregate.
