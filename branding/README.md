# Branding boundary

The application brand is Bankeiz; its Receiz identity and protocol integration remain unchanged. `identity.json` supplies the visible wordmark and application name for the console and entrance. It contains display strings only; it does not change identity custody, app registration, scopes, routing, rails, proof titles, verification or conformance.

The [proposed reference license](../LICENSE-PROPOSAL.md) would permit a narrow branding exception. It is not yet an effective grant. Replacement art and theme permissions, exact file schedules and integration configuration rights still require definitive terms. Do not add arbitrary logic or change protected behavior through this file.

The build validates a small fixed shape of bounded plain-text strings (the optional descriptor may be empty). Brands render as escaped text, not markup. The existing CSS continues to control typography and layout. The application name and wordmark are required.

Public page titles, the web manifest, icons and sharing artwork also identify the app. An approved rebrand must update those presentation assets consistently and retain necessary technical attribution; it must not rewrite proof schemas or suppress material status. These additional presentation changes remain explicit review work rather than a hidden runtime configuration mechanism.
